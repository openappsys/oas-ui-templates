# desktop —— 桌面软件体验模板（立项章程）

> 状态：**已立项（2026-10-06），v0 落地（桌面应用式布局）**
> 定位：模板仓第 8 个交付形态——**浏览器内的桌面软件体验**：单窗口原生应用式
> 布局（自绘标题栏 + 菜单栏 + 活动栏 + 状态栏），不是原生打包应用。

## 1. 背景与定位

oas-ui 是标准 web components，桌面软件体验即「把后台组织成原生应用的样子」：
自绘标题栏（窗口按钮）、菜单栏（文件/编辑/视图/帮助）、左侧活动栏（图标导航）
+ 侧栏面板 + 内容区、底部状态栏——参考 VS Code / 微信 PC 版的应用骨架。

**方向史**：2026-10-06 初版曾做成 OS 桌面（壁纸/桌面图标/多窗口管理器/任务栏），
用户定夺「像 OS 桌面，不像桌面软件」→ **推翻重做为桌面应用式单窗口布局**。
（更早的 Tauri 原生壳方向亦被否决——只要效果，不要原生打包。）

## 2. 交互范式（v0 已落地）

- **自绘标题栏**：应用名 + 最小化（收起为恢复药丸）/ 全屏（Fullscreen API）/
  关闭（退出确认弹窗 → 返回门户）
- **菜单栏**：文件（导出/退出）、编辑（刷新）、视图（玻璃质感切换/全屏）、
  帮助（关于）；下拉菜单真实生效
- **活动栏**：仪表盘/订单/用户/设置四 section 图标导航
- **侧栏面板**：随 section 更新的子导航（含计数/提示）
- **状态栏**：就绪状态 + 版本 + 在线标识

## 3. 技术口径

- 零框架 + web components（对齐 mobile-h5）：`@oas-ui/ui` 按需注册 +
  `@oas-ui/theme`（index/skins/glass）+ icons
- 标题栏/菜单栏/活动栏为模板自持布局壳；窗口按钮为浏览器内模拟
  （全屏走 Fullscreen API，关闭走退出确认 + 门户回链）
- 设置应用接全家族契约：`oas-admin.settings.skin` / `oas-admin.settings.glass`

## 4. 范围

### v0（已落地）
桌面应用式布局 + 四 section 内容（统计卡/表格/行内开关/皮肤玻璃）+
菜单动作（玻璃/全屏/刷新/退出确认）。

### v1（候选项，未排期）
内容区多标签页、菜单栏快捷键（Alt+F 等）、深浅色跟随系统、
side-panel 驱动内容筛选（订单状态联动）。

### 明确不做
原生打包（Tauri/Electron）、OS 桌面（壁纸/任务栏/多窗口）、离线数据层。

## 5. 验收

- e2e 5 用例：应用壳四件套渲染、活动栏切换、菜单玻璃动作、标题栏
  关闭确认/全屏、设置皮肤持久化
- `pnpm --filter desktop build` + e2e 全绿
